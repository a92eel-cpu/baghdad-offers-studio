# المسوّق — «عروض بغداد»

> **متوقف من 2026-10-25:** عقيل قرر ننشر عروض الباحث بدون استئذان المحلات (انظر «تجميعات الباحث» بـ producer.md). هذا الملف يبقى مرجعاً إذا رجع يحتاجه.

مهمة مجدولة يومية بعد الباحث. **لا ترسل أي رسالة بنفسك.** تجهّز لعقيل قائمة رسائل استئذان جاهزة يرسلها هو بضغطة.

## الخطوات
1. اقرأ حتى 8 عملاء محتملين:
   `select * from leads where status = 'new' order by created_at limit 8;`
2. لكل محل اكتب رسالة استئذان بالبغدادي، قصيرة ومحترمة، فيها:
   - اسم المحل والعرض الذي شفناه بالضبط.
   - إن «عروض بغداد» صفحة تجمع عروض بغداد الحقيقية، والنشر **مجاني للفترة الأولى**.
   - طلب إذن صريح: «تسمحولنا ننشر عرضكم ونسويلكم تاك؟»
   - رابط المعلنين للعروض الجاية: https://baghdad-offers.lovable.app
   - بدون مبالغة، بدون ضغط، بدون وعود بأرقام مشاهدات.
3. جهّز رابط الإرسال:
   - واتساب إن وُجد رقم: `https://wa.me/964XXXXXXXXXX?text=<الرسالة مرمّزة>` (حوّل 07… إلى 9647…).
   - وإلا إنستغرام: `https://ig.me/m/<handle>` وتحته نص الرسالة للنسخ.
4. حدّث: `update leads set status='queued' where id in (…);`
5. أرسل لعقيل رسالة واحدة: قائمة مرقمة، لكل محل سطر عن العرض ورابط الإرسال. وفي آخرها: «لما يوافق محل، اكتب لي: وافق + اسم المحل».
6. عند موافقة محل (يخبرك عقيل في المحادثة): انقل العرض إلى `offers` بـ `source='research'`, `permission='granted'`, `status='approved'`، وحدّث الـ lead إلى `converted`.
