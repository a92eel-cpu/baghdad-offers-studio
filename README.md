# استوديو عروض بغداد

أدوات وتعليمات الوكلاء اليومية لصفحة «عروض بغداد — Baghdad Offers».

- `studio.py` — قوالب 50/50: منشور 4:5، ستوري، سلايدات، ريلز من فيديو أو صور العميل، بمناطق أمان إنستغرام.
- `tips.py` — محتوى النصايح: ريلز نصيّة وسلايدات وستوري من `content/<YYYY-MM>.json`.
- `agents/` — تعليمات الباحث والمسوّق والمنتج وصانع المحتوى وحارس الانتهاء.
- `offers/` — بيانات العروض بصيغة studio.
- `media/<offer_id>/` — وسائط العملاء والمخرجات (روابط عامة تقرأها Metricool).

تشغيل: `python3 studio.py offers/<id>.json media/<id>/out --formats post,story,carousel,reel`

قاعدة ثابتة (من 2026-10-20 بطلب عقيل): كل شيء يُنشر تلقائياً. كل منشور يُجدول بـ `autoPublish: true`، وعقيل ما ينشر شيئاً بإيده. الحد الشهري 18 منشوراً في `posts` (الستوري تُحسب).
